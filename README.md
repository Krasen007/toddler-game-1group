# Игри за малките

Тази игра е предназначена за деца от 1-ва група (около 3 години) според Наредба № 5.

## Как да играете
Отворете index.html в браузър или достъпете през GitHub Pages.

## Характеристики
- Различни образователни игри (математика, български, околен свят, музика, физическа култура)
- Звуци и анимации
- Поддръжка за тъмен режим
- Цял екран
- Подходящо за таблет и телефон

## Онлайн
След публикуване ще бъде достъпно на GitHub Pages.
